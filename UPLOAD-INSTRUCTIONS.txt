RVZ Personnel Services — program package
=========================================

How to upload (cPanel File Manager):
1. Log in to cPanel: https://<your-cpanel-login>:2083
2. Open File Manager -> navigate to public_html (or a subfolder if you
   want the site at a path like public_html/careers).
3. Upload this zip file, then right-click it in File Manager and choose
   "Extract" -> extract into that same public_html folder, so index.php
   ends up directly inside public_html (or your chosen subfolder).
4. Delete the uploaded .zip afterwards (File Manager keeps it around
   otherwise, harmless but unnecessary).

Before it will work:
- Import the database first — see the separate database zip's
  HOW-TO-IMPORT.txt (import rvzrecruit_migration_2026-08.sql into the
  `rvzrecruit` database via phpMyAdmin).
- config/config.php is already fully filled in (DB host/name/user/password,
  SITE_URL, SMTP settings, the OpenAI key) — nothing to edit there unless
  a credential changes later.
- Make sure uploads/resumes, uploads/company_logos, uploads/profile_photos,
  uploads/ads, and uploads/slas are writable (755 is usually fine; try 775
  only if uploads fail with a permissions error).
- Set DEBUG_MODE to false in config/config.php once you've confirmed it
  works, so PHP errors aren't shown to visitors.
- Schedule cron/send_job_alerts.php to run daily via cPanel -> Cron Jobs
  (see README.md section 7b for the exact command).

See README.md in this same folder for the full setup guide, including
OAuth login and Paystack billing setup.
